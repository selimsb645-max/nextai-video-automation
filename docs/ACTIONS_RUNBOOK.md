# GitHub Actions অটো-প্রোডিউসার (স্বয়ংক্রিয় ভিডিও তৈরি)

এই রিপোর হার্ডকপি ব্যাকআপ নয় — এখন থেকে এটা একটা **স্বয়ংক্রিয় ভিডিও কারখানা** যা GitHub-এর ফ্রি সার্ভারে চলে। Base44 এজেন্টের ক্রেডিট শেষ হয়ে গেলেও ভিডিও চলতে থাকবে।

## কিভাবে কাজ করে
প্রতিদিন ২টি রান (Dhaka time):
- সকাল ০৯:১০ → সেদিন সন্ধ্যা ৬:৩০-র Long ভিডিও
- রাত ০৯:১০ → পরদিন সকাল ৬:৩০-র Long ভিডিও

প্রতিটি রান বাংলাদেশ সময়ের মালিক-অনুমোদিত স্লটের ৮-১০ ঘণ্টা আগে private আপলোড + publishAt লক করে। কখনো তাৎক্ষণিক পাবলিক হয় না।

**Follower ডিজাইন (ডুপ্লিকেট হবে না):** Base44 এজেন্ট ০৮:৩০/০৮:৩০ রাতে আগে ভিডিও বানালে এই রানার YouTube-এ দেখে স্লট ভরা আছে, তাই skip করে। এজেন্ট মারা গেলে (ক্রেডিট শেষ) এই রানারই স্লট ভরে দেয়। মানে দুইজন একসাথে চলে, কেউ আগে বানাবে ভিডিও তার, আর কেউ ডুপ্লিকেট আপলোড করবে না।

## প্রতি রানের ধাপ (সব ফ্রি টুল)
1. Google News RSS থেকে ৭ দিনের US ট্রেন্ডিং হেডলাইন সংগ্রহ
2. Gemini API (ফ্রি টিয়ার) দিয়ে টপিক বাছাই + স্ক্রিপ্ট (ভাইরাল ফিল্টার: AI + হুক শব্দ, শুধু অনুমোদিত নিশ)
3. Pexels API দিয়ে ওই ভিডিওর জন্য নতুন ফুটেজ (zero-reuse ledger সহ; key না থাকলে বান্ডেলড পুল)
4. Kokoro TTS (am_michael, emotion-aware) ভয়েসওভার
5. ffmpeg রেন্ডার (সব quality gate: clipping/quiet check)
6. YouTube Data API v3 private upload + publishAt
7. state + বাংলা রিপোর্ট রিপোতেই কমিট হয় (`actions/reports/`)

## রান দেখা / কন্ট্রোল (মালিকের জন্য)
- রানের লগ: https://github.com/selimsb645-max/nextai-video-automation/actions
- ম্যানুয়াল টেস্ট: Actions ট্যাব → "NextAI Content Factory" → Run workflow → mode: `selftest` (আপলোড ছাড়া ফুল টেস্ট)
- বন্ধ করতে: একই জায়গায় workflow disable করলেই হবে

## Secrets (সব encrypted, ফাইলে কোনো credential নেই)
- `YT_TOKEN_JSON` — YouTube OAuth refresh token (permanent, নিজের Google Cloud client)
- `GEMINI_API_KEY` — ফ্রি টিয়ার Gemini key (টপিক + স্ক্রিপ্ট + থাম্বনেল প্রম্পট)
- `PEXELS_API_KEY` — (অপশনাল) দিলে প্রতি ভিডিওর জন্য একদম নতুন ফুটেজ নামবে; না দিলে রিপোর সাথে থাকা পুল ব্যবহার হবে

## কোনো দিন ভিডিও না উঠলে চেক করো
1. Actions ট্যাবে লাল ক্রস আছে কিনা → লগ পড়ে Run workflow (produce) দিয়ে পুনরায় চালাও
2. স্লট আগেই ভরা থাকলে রানার ইচ্ছা করেই skip করে — এটা স্বাভাবিক
3. `NO_ELIGIBLE_CONTENT` এলে Gemini key/quota শেষ হয়েছে কিনা দেখো (AI Studio API keys পেজে নতুন ফ্রি key বানিয়ে secret আপডেট করো)

## থাম্বনেল
প্রতি রানের রিপোর্টে (`actions/reports/`) রেডি থাম্বনেল প্রম্পট থাকবে — মালিক ChatGPT-তে বানিয়ে নিজে বসাবেন (আগের নিয়মই বহাল)।
